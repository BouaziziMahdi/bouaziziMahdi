### 🔥 Data Engineering Pipeline — Airflow, Kafka, Spark & Delta Lake

End-to-end data engineering pipeline designed for scalable
data ingestion, real-time processing, and analytics.

- Automated data ingestion from external APIs using Apache Airflow
- Real-time event streaming with Apache Kafka
- Data transformation using PySpark and Spark Structured Streaming
- Delta Lake architecture with Bronze, Silver, and Gold layers
- Fault-tolerant processing using Spark checkpoints

**Tech Stack:** Python · Apache Airflow · Apache Kafka ·
Apache Spark · PySpark · Delta Lake · Docker

---

### 🤖 Airflow Repair AI — Self-Healing Data Pipelines

AI-powered system for detecting, diagnosing, and repairing
failures in Apache Airflow workflows.

- Automated analysis of failed DAGs and execution logs
- LLM-powered root cause analysis and repair suggestions
- Intelligent AI workflows using LangGraph and RAG
- Isolated Docker environments for DAG validation
- PostgreSQL integration for execution history and tracking

**Tech Stack:** Python · Apache Airflow · LangGraph ·
LLMs · RAG · PostgreSQL · Docker

AI-powered research platform for collecting, analyzing,
and identifying emerging technology trends.

- Automated data collection from Reddit, Hacker News,
  and Product Hunt
- Data processing, transformation, and PostgreSQL storage
- LLM integration through OpenRouter for trend classification
- Automatic generation of insights and trend summaries
- REST APIs and dashboard for monitoring research results

PostgreSQL · OpenRouter · LLMs · Docker
